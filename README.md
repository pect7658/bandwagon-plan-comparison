## 一、搬瓦工特价到底"特"在哪里

搬瓦工的"特价"其实分两层意思。

第一层是**常年低价的基础套餐**。比如 KVM PROMO 系列，20G 那款年付只要 49.99 美元，折合人民币三百出头，平均一天不到一块钱。这个价格在海外 VPS 市场里属于地板价了，而且支持支付宝付款，后台还能一键切换机房，对国内用户来说门槛很低。
